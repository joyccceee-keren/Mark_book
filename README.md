# Mark: Know Jesus 📖

A modern, simple, and engaging mobile Bible learning application based on the **Gospel of Mark**. It is designed to help users understand each chapter deeply through summaries, explanations, interactive games, quizzes, and progressive learning levels.

Live App Demo: [https://rad-hamster-fc23be.netlify.app](https://rad-hamster-fc23be.netlify.app)

---

## 🌟 Key Features

1. **Chapter Selection**: Access to all 16 chapters of Mark (fully completed Chapter 1 with lock/unlock progression).
2. **Tabbed Learning System**:
   - **Summary**: Concise overview of key events.
   - **Understand**: Deeper explanations detailing what happened, teachings of Jesus, character traits of Christ, and practical spiritual lessons.
   - **Timeline**: Visual chronological flows of Gospel events.
   - **People & Places**: Interactive profile cards explaining historical people and places.
   - **Key Verses**: Scripture focus with a togglable "Remember This" memorization helper.
3. **Bible Game Arena**: Six interactive game formats:
   - **Who Said It?**: Match spoken quotes to the speaker.
   - **Who Am I?**: Identify biblical personalities using clues.
   - **What Happened Next?**: Order consecutive timeline events.
   - **Match the Following**: Coordinate columns of people, places, and descriptions.
   - **Put It in Order**: Drag-and-arrange chronological order matching.
   - **True or False**: Simple facts validator.
4. **Quiz Engine**: 10 chapter-specific questions with immediate visual and textual feedback explaining *why* the answer is correct or incorrect.
5. **Mistakes Review System**: Tracks incorrectly answered quiz questions and enables retrying them to reinforce memory.
6. **XP & Badge Progression**: Gamification mechanics to track daily streaks, level badges (Discoverer, Explorer, Disciple, Teacher, Mark Master), and unlock characteristics of Jesus.
7. **Search Engine**: Search and filter occurrences of key terms (like "Peter", "Galilee", etc.) across unlocked teachings, events, and people.
8. **WhatsApp Share integration**: Easily share quiz results, streak milestones, or overall progress with friends!

## 🛠️ Technology Stack

- **Core**: HTML5
- **Style**: Custom Vanilla CSS (Peaceful Christian aesthetic with Indigo, Linen cream, and Gold accents)
- **Logic**: Vanilla ES6 JavaScript (State is saved automatically in `localStorage`)
- **Frameworks**: None (pure client-side static application, lightweight and fast)

## 💻 Running Locally

To run the application on your computer:

1. Clone this repository:
   ```bash
   git clone https://github.com/joyccceee-keren/Mark_book.git
   ```
2. Navigate to the directory:
   ```bash
   cd Mark_book
   ```
3. Run a static local server (e.g. using Python):
   ```bash
   python -m http.server 8000
   ```
4. Open your web browser and go to `http://localhost:8000`.
